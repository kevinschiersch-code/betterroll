# BetterRoll – Datenschutz / Privacy

**Deutsch**

BetterRoll ist ein inoffizielles Add-on und nicht mit Crunchyroll verbunden.

- Es gibt keine Anmeldung im Add-on. BetterRoll liest weder Passwörter noch Anmelde-Tokens oder Kontodaten.
- Es werden keine Daten gesammelt oder an den Entwickler gesendet. Kein Tracking, keine Statistik, keine Werbung.
- Einstellungen, Favoriten, der Fortschritt gesehener Folgen und zwischengespeicherte Kalenderdaten, Poster und Bewertungen liegen nur im Browser (Browser-Speicher des Add-ons). Einstellungen und die Liste der markierten Anime-Titel (★/▼) gleicht der Browser über seine eigene Synchronisierung (Google-Konto) zwischen deinen Geräten ab, sofern du sie eingeschaltet hast; BetterRoll selbst sendet dabei nichts.
- Für den Release-Kalender ruft BetterRoll bei crunchyroll.com dieselben öffentlichen Kalenderdaten ab wie die Kalender-Seite von Crunchyroll selbst: mit dem anonymen Zugang für nicht angemeldete Besucher, ohne Cookies und ohne Konto. Dabei werden keine persönlichen Daten gesendet.
- Für Poster und Bewertungen fragt BetterRoll den öffentlichen Dienst AniList (graphql.anilist.co) an. Dabei wird nur der Anime-Titel gesendet.
- Crunchyroll-Seiten (Serienseiten, Player) werden nur so gelesen, wie sie im Browser ohnehin angezeigt werden.
- Nur private Fassung mit Windows-Installer (nicht im Chrome Web Store): Automatische Updates laden eine öffentliche Versionsdatei und das Update-Paket; dabei werden keine Daten gesendet.

**English**

BetterRoll is an unofficial add-on and is not affiliated with Crunchyroll.

- There is no login in the add-on. BetterRoll never reads passwords, login tokens or account data.
- No data is collected or sent to the developer. No tracking, no analytics, no ads.
- Settings, favourites, the progress of watched episodes and cached calendar data, posters and ratings stay in the browser (the add-on's browser storage). Settings and the list of marked anime titles (★/▼) are synced between your devices by the browser's own sync (Google account) if you have it turned on; BetterRoll itself sends nothing.
- For the release calendar BetterRoll requests the same public calendar data from crunchyroll.com that Crunchyroll's own calendar page loads: with the anonymous access used for visitors who are not signed in, without cookies and without an account. No personal data is sent.
- For posters and ratings BetterRoll queries the public service AniList (graphql.anilist.co). Only the anime title is sent.
- Crunchyroll pages (series pages, player) are only read as they are shown in the browser.
- Private version with Windows installer only (not in the Chrome Web Store): automatic updates download a public version file and the update package; no data is sent.
