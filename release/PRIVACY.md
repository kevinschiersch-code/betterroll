# BetterRoll – Datenschutz / Privacy

**Deutsch**

BetterRoll ist ein inoffizielles Add-on und nicht mit Crunchyroll verbunden.

- Es gibt keine Anmeldung im Add-on. BetterRoll liest weder Passwörter noch Tokens oder Kontodaten.
- Es werden keine Daten gesammelt, gespeichert oder an den Entwickler gesendet. Kein Tracking, keine Statistik.
- Einstellungen, Favoriten und zwischengespeicherte Bilder/Bewertungen liegen nur im Browser (Browser-Speicher des Add-ons). Einstellungen und die Liste der markierten Anime-Titel (★/▼) gleicht der Browser über seine eigene Synchronisierung (Google- bzw. Firefox-Konto) zwischen deinen Geräten ab, sofern du sie eingeschaltet hast; BetterRoll selbst sendet dabei nichts.
- Für Poster, Bewertungen, Kommentare und News fragt BetterRoll öffentliche Dienste an: AniList (graphql.anilist.co), Anime News Network (cdn.animenewsnetwork.com) und als Ersatz MyAnimeList über Jikan (api.jikan.moe). Dabei wird nur der Anime-Titel gesendet.
- Crunchyroll-Seiten (Kalender, Serienseiten) werden nur so gelesen, wie sie im Browser ohnehin angezeigt bzw. bei einem normalen Seitenaufruf geladen werden.
- Eigenes Hintergrundbild (Design „Bild“): Eine Datei vom PC bleibt auf dem PC. Bei einer Bild-Adresse fragt der Browser vorher nach Zugriff auf genau diese Seite; das Bild wird einmal geladen und verkleinert im Browser gespeichert.
- Automatische Updates (Windows-Installer) laden nur eine öffentliche Versionsdatei und das Update-Paket; dabei werden keine Daten gesendet.

**English**

BetterRoll is an unofficial add-on and is not affiliated with Crunchyroll.

- There is no login in the add-on. BetterRoll never reads passwords, tokens or account data.
- No data is collected, stored or sent to the developer. No tracking, no analytics.
- Settings, favourites and cached images/ratings stay in the browser (the add-on's browser storage). Settings and the list of marked anime titles (★/▼) are synced between your devices by the browser's own sync (Google or Firefox account) if you have it turned on; BetterRoll itself sends nothing.
- For posters, ratings, comments and news BetterRoll queries public services: AniList (graphql.anilist.co), Anime News Network (cdn.animenewsnetwork.com) and, as a fallback, MyAnimeList via Jikan (api.jikan.moe). Only the anime title is sent.
- Crunchyroll pages (calendar, series pages) are only read as they are shown in the browser or loaded by a normal page visit.
- Custom background image ("Image" design): a file from your PC stays on your PC. For an image address the browser first asks for access to exactly that site; the image is loaded once and stored, downscaled, in the browser.
- Automatic updates (Windows installer) only download a public version file and the update package; no data is sent.
